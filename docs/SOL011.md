# SOL011 — Strings

## Description

`str` is an immutable byte view, conventionally UTF-8. Ordinary quotes, basic escapes (`\n`, `\r`, `\t`, `\0`, escaped quotes/backslashes), and embedded zero bytes are supported. Indexing and lengths use bytes, not characters. See SOL017 for operations.

## Example

```sole
import core

def main() -> void:
    message: str = "Hello\nSole ☀"
    core.print(message)
```
