# SOL015 — Growable arrays

## Description

`T[]` is a growable array. `core.append(array, value)` adds one element. Assignment shares the same array; indexes are bounds-checked. Fixed `T[N]` arrays still copy by value.

## Example

```sole
import core

def main() -> void:
    values: int32[] = []
    core.append(values, 42)
    core.print(values[0])
```
