# SOL013 — Memory and safety

## Description

Classes, growable arrays, and allocated strings live for the process lifetime; memory is not reclaimed yet. Invalid indexes, slices, integer division, shifts, and float-to-integer casts trap. Variables must be initialized; recursive inline struct layouts are rejected. Unsafe pointers bypass these guarantees.

## Example

```sole
import core

def main() -> void:
    values: int32[2] = [10, 20]
    core.print(values[2])  # Traps: index out of bounds.
```
