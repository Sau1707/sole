# SOL018 — System operations

## Description

Native programs use `core.arg_count()` and `core.arg(index)` for arguments; argument zero is the executable name. `core.read_file(path)` returns bytes as `str`; `core.write_file(path, text)` writes them. `core.exit(status)` terminates the process. I/O failures terminate with an error.

## Example

```sole
import core

def main() -> void:
    core.write_file("message.txt", "Hello, Sole!")
    core.print(core.read_file("message.txt"))
    core.print(core.arg(0))
```
