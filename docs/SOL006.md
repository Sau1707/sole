# SOL006 — Loops

## Description

`while` is the only loop construct. `break` exits the nearest loop; `continue` checks its condition again. Use `pass` for an empty block.

## Example

```sole
import core

def main() -> void:
    i: int32 = 0
    while i < 3:
        core.print(i)
        i = i + 1
```
