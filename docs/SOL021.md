# SOL021 — Standard library

## Description

`lib/pure/` contains portable Sole modules. `lib/impure/` contains Sole APIs backed by native dependencies. `lib/wrappers/` contains unsafe foreign declarations. Search follows that order after `lib/`; `SOLE_LIB` overrides the library root. Explicit category paths are supported.

Python-style subsets include `bisect` for sorted `int64[]` arrays, `statistics`
for `float64[]` samples, and `os.path` for lexical POSIX path operations. See the
[library reference](../lib/README.md) for supported functions and compatibility limits.

## Example

```sole
import core

import strings
import wrappers.cmath

def main() -> void:
    core.print(strings.repeat("Sole!", 2))
    core.print(wrappers.cmath.sqrt(16.0))
```
