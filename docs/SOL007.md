# SOL007 — Structs

## Description

Structs contain public typed fields, without methods. Constructors take every field in declaration order. Assignment and function calls copy struct values.

## Example

```sole
import core

struct Point:
    x: int32
    y: int32

def main() -> void:
    point: Point = Point(1, 2)
    copy: Point = point
    copy.x = 9
    core.print(point.x)  # 1
```
