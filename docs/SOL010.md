# SOL010 — Casts

## Description

Typed numeric values require explicit type-name casts. Integer narrowing keeps low bits; float-to-integer casts truncate and trap outside the allowed range. Literals adopt their numeric context and must fit their integer type; otherwise they default to `int64` or `float64`.

## Example

```sole
import core

def main() -> void:
    small: int8 = 127
    wide: int64 = int64(small)
    wrapped: uint8 = uint8(int32(257))
    core.print(wrapped)  # 1
```
