# SOL016 — Pointers and C interop

## Description

`extern def` declares a C function with scalar or `ptr` parameters/results. `cstr` makes a zero-terminated copy; `from_cstr` views a valid C string. `core.address(variable)` exposes storage; `ptr(0)` is null. This is unsafe: callers must match the C ABI and pointer lifetimes. Link libraries with `--link NAME`.

## Example

```sole
import core

extern def strlen(text: ptr) -> uint64

def main() -> void:
    core.print(strlen(core.cstr("Sole")))
```
