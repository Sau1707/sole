# SOL012 — Core operations

## Description

`core.print(value)` prints one number, boolean, or string followed by a newline.
`core.len(value)` returns an `int64`: an array's element count or a string's UTF-8
byte count. Both require `import core`, just like every other library function.
Bare names such as `len` and `print` are not implicitly available or reserved.

`lib/core.sole` exports `print`, `len`, `append`, `slice`, `join`, `cstr`,
`from_cstr`, `address`, `arg_count`, `arg`, `read_file`, `write_file`, and `exit`.
Type casts and record constructors remain language constructs.

Core operations are declared with `intrinsic NAME` in the library. Only the
supported operation names are accepted. The declaration exposes the operation
through the module namespace while the compiler supplies its type-dependent
implementation. Imports are module-local and do not re-export dependencies.

## Example

```sole
import core

def main() -> void:
    core.print(core.len("☀"))  # 3 bytes
    core.print(true)         # true
```
