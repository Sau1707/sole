# SOL004 — Operators

## Description

Numbers support `+`, `-`, `*`, `/`, `%`, and comparisons. Integers also support bitwise operators and shifts. Integer arithmetic wraps; division truncates toward zero. `and`, `or`, and `not` require booleans; `and` and `or` short-circuit. No `+=` or chained comparisons.

## Example

```sole
import core

def main() -> void:
    value: int32 = 7 / 3
    core.print(value == 2 and not false)
```
