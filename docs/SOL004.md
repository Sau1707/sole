# SOL004 — Operators

## Description

Numbers support `+`, `-`, `*`, `/`, `%`, and comparisons. Integers also support bitwise operators and shifts. Integer arithmetic wraps; division truncates toward zero. `&&`, `||`, and `not` require booleans; `&&` and `||` short-circuit, with `&&` binding more tightly than `||`. Single `&` and `|` remain integer bitwise operators. The word forms `and` and `or` are not operators. No `+=` or chained comparisons.

## Example

```sole
import core

def main() -> void:
    value: int32 = 7 / 3
    core.print(value == 2 && not false)
```
