# SOL009 — Arrays

## Description

`T[N]` is a fixed-size array copied by value. A literal must supply exactly `N` elements. Integer indexes start at zero and are bounds-checked. No resizing, slicing, or nested array types.

## Example

```sole
import core

def main() -> void:
    values: int32[3] = [10, 20, 30]
    values[1] = 99
    core.print(values[1])
```
