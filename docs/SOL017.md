# SOL017 — String operations

## Description

Use `+` to concatenate, `==`/`!=` to compare bytes, and `text[index]` to read a `uint8`. `core.slice(text, start, stop)` returns a checked byte view. `core.join(parts: str[])` joins without a separator; `str(integer)` formats a decimal integer.

## Example

```sole
import core

def main() -> void:
    parts: str[] = ["Sole ", str(42)]
    text: str = core.join(parts)
    core.print(core.slice(text, 0, 4) == "Sole")
```
