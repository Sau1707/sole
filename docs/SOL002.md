# SOL002 — Types and variables

## Description

Declare each variable with a type and initial value. Types include `int8`–`int64`, `uint8`–`uint64`, `float32`, `float64`, `bool`, `str`, and unsafe `ptr`. Reassignment keeps the same type; shadowing is forbidden.

## Example

```sole
def main() -> void:
    count: int32 = 1
    count = count + 1
    ready: bool = true
```
