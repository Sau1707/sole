# SOL019 — Self-hosting

## Description

`compiler/main.sole` starts a modular Sole-written compiler using LLVM's C API.
`bootstrap.sh` uses an existing `.build/sole` or the checksummed native seed in
`bootstrap/sole`. It builds three generations and requires stages 2 and 3 to be
byte-identical. No Python compiler, interpreter, or package is required.
The bundled seed targets Linux x86-64 and the LLVM 21.1 shared-library ABI;
`SOLE_BOOTSTRAP` can select another compatible native Sole compiler. LLVM and
the native C toolchain remain dependencies. `./bootstrap.sh --seed` explicitly
starts from the bundled seed.

`sh install.sh /absolute/prefix` installs the executable and its runtime/library
resources. The installed tree is relocatable: resource lookup is relative to the
executable, with `SOLE_HOME` and `SOLE_LIB` available as explicit overrides.

## Example

```sh
./bootstrap.sh
./compiler/tests/run.sh
```
