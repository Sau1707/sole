# SOL001 — Syntax

## Description

Use spaces for indentation and `#` for comments. Module scope contains imports, functions, `extern` declarations, structs, and classes. No semicolons, comprehensions, or single-line blocks.

`#` starts a comment that ends at the end of the line, either on its own or after code. Inside strings, `#` is ordinary text.

Python-style docstrings are standalone string literals at the beginning of a module, struct, class, or indented block (including functions and methods). Use `"""..."""` for multiline documentation; `'''...'''` also works. Docstrings are ignored during compilation and have no runtime metadata. Comments and blank lines may precede them. A docstring alone is sufficient for an otherwise empty body.

Triple-quoted strings can also be used as ordinary string values. They preserve embedded newlines and support the same escapes as single-line strings.

## Example

```sole
import core

"""An example module."""

def main() -> void:
    """Print a greeting."""
    # A block uses indentation.
    core.print("Hello, Sole!")  # A trailing comment.
```
