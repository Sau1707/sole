# SOL014 — Compilation

## Description

LLVM compiles Sole to native binaries. Executables need a parameterless `main` returning `int32` or `void`. Use `--emit llvm` or `--emit object` to produce LLVM IR or a relocatable object without linking, and `--link NAME` to link a native library.

## Example

```sh
sole build hello.sole -o hello
./hello
```
