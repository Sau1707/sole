# SOL005 — Conditions

## Description

Use `if`, optional `elif` branches, and optional `else`. Conditions must be `bool`. Variables declared inside a branch stay inside it.

## Example

```sole
import core

def describe(value: int32) -> void:
    if value == 0:
        core.print("zero")
    elif value < 0:
        core.print("negative")
    else:
        core.print("positive")
```
