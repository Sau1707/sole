# SOL008 — Classes

## Description

Classes have public typed fields and methods beginning with `self`. Constructors take every field in declaration order. Assignment copies the reference, so aliases share mutations. No inheritance or custom constructors.

## Example

```sole
import core

class Counter:
    value: int32

    def increment(self) -> void:
        self.value = self.value + 1

def main() -> void:
    counter: Counter = Counter(0)
    alias: Counter = counter
    alias.increment()
    core.print(counter.value)  # 1
```
